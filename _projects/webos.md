Connected Platform Theory and Practice (fall 2024): a webOS TV app that recommends restaurants and plays their videos, with a backend and a data scraper.

- **My part:** the TV front end in Enact (React): search, profile selection, restaurant pages, and a dashboard of the TV's CPU and memory use. I mocked the REST API and webOS services so the UI could be built and tested without the TV or the backend.
- **Testing:** Postman unit tests for each API endpoint, and system tests for the TV UI written from the use cases.
