# seungwooLee00.github.io

Personal homepage of Seungwoo Lee, built with [al-folio](https://github.com/alshedivat/al-folio) v1.2.

- Content: `_pages/` (about, publications, projects, CV), `_projects/`, `_news/`, `_bibliography/papers.bib`, `_data/cv.yml`
- Deploy: pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.
